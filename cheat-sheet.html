tmuxwith your ~/.tmux.conf

Every shortcut starts with your prefix, Ctrl+a: press it, let go, then press the next key. Keys shown without C-a are pressed on their own.

  • C-a your prefix, Ctrl+a
  • C-s Ctrl+s   M-w Alt+w
  • set up in your config or its plugins

0Sessions

  • tmuxStart tmux
  • tmux new -s workStart a new session named work
  • tmux lsList running sessions
  • tmux a -t workAttach to the session named work
  • tmux aAttach to the most recent session
  • tmux new -A -s mainAttach to main, or create it if it isn’t there
  • tmux kill-session -t workClose the session named work
  • tmux kill-serverClose every session and tmux itself
  • C-adDetach. Everything keeps running.
  • C-asPick a session from a list
  • C-a$Rename this session
  • C-a(/)Previous / next session
  • C-aLBack to the last session you used

1Windows

  • C-acNew window
  • C-a,Rename this window
  • C-an/pNext / previous window
  • C-a0…9Go to a window by its number
  • C-awPick a window from all sessions
  • C-afFind a window by text on its screen
  • C-a&Close this window asks y/n
  • click status barSwitch to the window you click
  • scroll status barStep through windows

2Panes

  • C-a|Split side by side, in the same folder
  • C-a-Split top and bottom, in the same folder
  • C-ahjklMove to the pane left, below, above, right
  • C-a← ↑ ↓ →Move to the pane in that direction
  • C-a;Back to the previous pane
  • C-aoNext pane
  • C-aqShow pane numbers; press one to jump there
  • C-azZoom this pane to the whole window, and back
  • C-axClose this pane asks y/n
  • C-a{/}Swap with the previous / next pane
  • C-a!Move this pane into its own window
  • C-aSpaceCycle through the built-in layouts
  • C-aM-1…M-5Preset layouts: side by side, stacked, big pane on top, big pane on left, grid
  • C-a:setw synchronize-panesType into every pane in this window at once; run it again to stop
  • C-aC-← ↑ ↓ →Resize by 1 cell keep tapping within half a second to repeat
  • C-aM-← ↑ ↓ →Resize by 5 cells
  • click a paneMake it the active pane
  • drag a borderResize the panes on both sides
  • right-click a paneMenu to split, zoom, swap or close

3Scroll & copy

  • scroll wheelScroll back through the output
  • C-a[Enter copy mode; scroll with arrows, PgUp, PgDn
  • C-aPgUpEnter copy mode one page up
  • C-s/C-rSearch down / up in copy mode
  • C-SpaceStart a selection in copy mode
  • M-wCopy the selection and leave in copy mode
  • qLeave copy mode
  • C-a]Paste what you copied last
  • C-a=Pick from everything you copied
  • tmux capture-pane -pS - > out.txtSave this pane’s whole scrollback to out.txt
  • dragSelect text; it is copied when you let go
  • double / triple clickCopy a word / a line
  • Shift + dragSelect with Ghostty instead of tmux

4Save & restore

  • C-aC-sSave all sessions now; do this before a reboot
  • C-aC-rRestore the last save
  • every 15 minSaved on its own while tmux runs
  • tmuxAfter a reboot, brings back the last save
  • on restorevim, nvim, less, man, htop, top and tail start again; other panes come back as a shell in the same folder

5Help & config

  • C-a?List every key binding
  • C-a/Press any key to see what it does
  • C-a:Type a tmux command
  • C-aC-aSend a real Ctrl+a, such as start of line in fish
  • C-atShow a big clock; any key closes it
  • tmux source ~/.tmux.confReload your config after editing it
  • C-aIInstall plugins listed in ~/.tmux.conf
  • C-aUUpdate plugins
